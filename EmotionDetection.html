How this works. Raspberry Pi devices running on-device detection models capture frames and push results — including posture, hand gesture / habit signals, and inference speed — to this dashboard automatically. Each device registers itself the first time it sends data — no configuration needed here when a new device is added. Images and results live in memory only, are never written to disk, and are automatically cleared if a device stops reporting for 30 minutes. This is a general expression estimate, not a clinically validated emotion score.
